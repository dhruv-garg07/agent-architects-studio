Common Issues

How do I increase my API limit?

You can upgrade your plan in the Billing section to get higher rate limits instantly.

Where can I find my API Key?

Navigate to the API Keys page in your workspace sidebar.

How do I add memories to my agent?

You can add memories via the API using your API key, or through the Explorer in the sidebar. Each memory is automatically embedded and indexed for semantic search.

Can agents share memory with each other?

Yes! Use the Agentic Sharing page to set up inter-agent memory connections with fine-grained permission scopes.

How do snapshots and version history work?

GitMem automatically creates version snapshots of your agent's memory state. You can view, compare, and restore previous versions from the History page.

Model Context Protocol (MCP)

The open standard for connecting AI assistants to external tools and data sources. GitMem exposes an MCP server so any compatible client can search, read, and write your agent's memory.

What is MCP?

Model Context Protocol (MCP) is an open specification created by Anthropic that standardises how AI assistants connect to external data and tools. Instead of building custom integrations for every tool, MCP provides a universal interface — similar to how USB standardised hardware connections.

GitMem runs an MCP server that exposes your agent's memory as a set of tools. Any MCP-compatible client (Claude Desktop, Claude Code, Cursor, Windsurf, VS Code + Copilot, and more) can connect to this server and:

Search Memory Semantic search across all your agent's stored knowledge
Add Memories Store new context, decisions, and learnings
List & Browse Navigate categories, files, and memory snapshots
Version History Access snapshots and diffs of your memory over time

AI Client Setup Guides

Copy-paste configuration to connect your favourite AI coding assistant to GitMem's MCP server.

Claude Desktop Anthropic's desktop app

Add the following to your claude_desktop_config.json file. On macOS this is at ~/Library/Application Support/Claude/claude_desktop_config.json, on Windows at %APPDATA%\Claude\claude_desktop_config.json.

claude_desktop_config.json 
{
  "mcpServers": {
    "gitmem": {
      "url": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
Replace YOUR_API_KEY with a key from your API Keys page. Restart Claude Desktop after editing the config.
Claude Code (CLI) Anthropic's coding agent

Add the MCP server to your project's .mcp.json file (or ~/.claude/settings.json for global access):

.mcp.json 
{
  "mcpServers": {
    "gitmem": {
      "type": "sse",
      "url": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Or add via the CLI directly:

Terminal 
claude mcp add gitmem \
  --transport sse \
  --url "{{ request.host_url }}mcp/sse" \
  --header "Authorization: Bearer YOUR_API_KEY"
Cursor AI-first code editor

Cursor supports MCP natively. Create a .cursor/mcp.json file in your project root:

.cursor/mcp.json 
{
  "mcpServers": {
    "gitmem": {
      "url": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
After saving, open Cursor's MCP panel (Cursor Settings → MCP) to verify the server is connected and tools are available.
Windsurf Codeium's AI IDE

Create a ~/.codeium/windsurf/mcp_config.json file (or configure through Windsurf Settings → MCP):

mcp_config.json 
{
  "mcpServers": {
    "gitmem": {
      "serverUrl": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
VS Code + GitHub Copilot With MCP support in Copilot Chat

GitHub Copilot in VS Code supports MCP servers. Add the following to your project's .vscode/mcp.json:

.vscode/mcp.json 
{
  "servers": {
    "gitmem": {
      "type": "sse",
      "url": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
Ensure you have the latest GitHub Copilot extension and MCP support enabled in VS Code settings.

      "uri": "{{ request.host_url }}mcp/sse",

}
Custom / Any MCP Client Generic SSE transport

Any client that supports the MCP specification can connect using the SSE transport. The general pattern:

Connection Details 
Transport:  SSE (Server-Sent Events)
Endpoint:   {{ request.host_url }}mcp/sse
Auth:       Bearer YOUR_API_KEY (via Authorization header)
Protocol:   MCP v1.0

See the MCP specification ↗ for full protocol details.
